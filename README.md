The Gilded Gallery — a top-down night-museum heist. Play Wren, a thief slipping through three gallery rooms after closing time: steal every treasure, read the guards' vision cones, blind the cameras with smoke and fuse boxes, and leave before the alarm hits 100.

## How to play

- **WASD / arrows** — move, **Shift** — sneak (slower, quieter)
- **E** — grab loot, **Q** — smoke pellet, **F** — fuse box (kills all cameras for 15 s, +8 alarm)
- **P** — pause, **M** — mute
- Grab every treasure to open the green exit. If the alarm hits 100, you're busted — retry the room.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
